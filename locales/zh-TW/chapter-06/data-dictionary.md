# 第 6 章：原創假設資料字典

- `month`：依時序排列且不重複的月份標籤，2025 年 1–6 月。這些是虛構例子，不是歷史市場資料。
- `a_return_pct`：A 的月簡單總報酬率，以百分比數值表示；5 代表 5%，不是 .05。已含收益分配。
- `b_return_pct`：相同日期、相同基礎的 B 月簡單總報酬率；B 是第二項資產。
- `market_return_pct`：同日示範基準的月簡單總報酬率，以百分比數值表示。

觀察值皆為有限數值，沒有缺月，不含外部現金流、費用、稅或交易成本。初始財富 100 是假設貨幣單位，不是價格。原創教學資料隨儲存庫發布，無需市場資料授權或 API 金鑰。保留日期配對，不要將兩條報酬率序列各自排序。

`comparison-examples.csv` 包含與文字指引相同的兩次固定預備執行。互動 JSON 匯出保留輸入、預測與時間戳記。互動 CSV 匯出包含每次保留的執行：`run`、`input`、`month`（0 代表初始）、`value1`、`value2`、`detail`。本章 input 是 A 目標／初始百分比，value1 是固定比例財富、value2 是買進持有財富、detail 是期末買進持有 A 比例。不含成本。

改變輸入會產生另一筆保留的固定執行，沒有隨機產生器或種子。只比較相符日期。匯出是紀錄，不是匯入或同步機制。金額若標 £，幣別為英鎊，不是新臺幣。

# Ten-chapter prototype manifest and alignment

Status: formative self-learning prototype; proposed30-hour noncoding core plus optional Python time. No credential or learning-effectiveness validation. Original course-level assessment weights remain a proposed design, not an implemented secure course-wide grade. Prototype completion records document supplied arithmetic/integrity checks and self-reviewed explanations; they do not establish general research mastery.

Total intended core1800minutes=30hours. See [current workload](current-workload.md) for the implemented step-by-step allocation. Learner timing is unvalidated. Every chapter has `dist/chapter-NN/` (Chapter1 uses `dist/`), local progress/privacy/reset/export and a text/paper guide. The course map is `dist/course/index.html`; optional Python is `dist/python/index.html` with starters, references, local checks and learner ZIP. Instructor files live outside `dist/`; the public repository still makes them inspectable. Code/tests/check answers are formative and visible by design.

Generation: `npm run build:guide`, `npm run build:python`, `npm run build:navigation`. Node24 required for JS build/check tools. Core static site has no installation requirement; Python runtime downloads on demand from pinned jsDelivr. Downloaded scripts use standard-library Python3.8-compatible syntax and do not access brokers or require keys. Browser execution, CDN/network caveats, local retention and responsiveness limits are described in the Python setup guide.

Dataset and source contract: all supplied finance examples are original synthetic or hypothetical; no historical market performance or redistribution licence is inferred. Seeds identify teaching generators only. Chapter5 specifies sample/frequency/annualisation; Chapter6 declares rebalance/cost assumptions; Chapters7–10 disclose model/timing/split/trial/cost limitations. Chapter9/10 browser-local freeze/reveal teaches ordering, not third-party registration or tamperproof blindness. Local clocks, editable storage and downloadable source are not evidentiary controls.

Review records: `review/chapters-05-10/` plus earlier chapter records. Independent agent review is not target-learner efficacy or full accessibility evidence. This package has no payments, promised facilitator service, LMS enrolment/account sync, consequential automated grading, live execution or commercial-release certification. Appropriate next validation is a consented target-learner pilot with timing, reasoning, accessibility and support observations.

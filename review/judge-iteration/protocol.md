# Independent judge iteration

Date: 1 November 2026. User confirmed independent AI judge review (not a separate Judget service). Baseline Git commit402603a, implementation3d77efa. Fixed rubric: alignment, assessment/feedback, quantitative validity, reproducibility, accessibility/learner experience, product truth. Each dimension:0 absent,1 major gaps,2 usable with minor gaps,3 demonstrated within explicitly reviewed scope. Sum0–18 is an internal review indicator, not a learner grade, independent certification or a measurement of educational effectiveness.

Two independent reviewers inspect the actual course assets, brief, proposal and instructor resources. Quant/curriculum reviewer covers dimensions1–4, UX/product reviewer covers5–6. Root implements revisions and performs browser QA; reviewers do not author the fixes. One baseline round and one recheck round, with targeted follow-up only for unresolved defects. Ratings use the same anchors and include scope, evidence and unresolved limitations. A score is not increased merely because a change was made.

Acceptance: no unresolved blocker/major within reviewed scope; meaningful tests pass; local progress and numerical conventions preserved; source/data limitations retained; rating history and changes logged; GitHub source and existing owner-private site updated. Real-learner pilot, full assistive-technology testing, rights/legal/commercial review remain separate.

Model and cost plan: reuse existing review agents with inherited session model/settings; no external paid API calls, model variants or price benchmarks. At most four planned judge turns (two initial, two rechecks), plus bounded root revision and tests. Exact provider model usage and pricing are not exposed by these tools; log unknowns without substituting API price estimates. No monetary budget was supplied; no claim of priced budget clearance or zero cost is made. Local deterministic tests are excluded from model-token accounting, and compute costs are unmeasured.

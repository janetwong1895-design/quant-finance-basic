## 本機啟動

需要 Python 3。請透過 HTTP 啟動，不要直接雙擊 HTML：

```sh
python3 -m http.server 8765 --bind 127.0.0.1 --directory dist
```

開啟 [繁體中文介紹頁](http://127.0.0.1:8765/zh-tw/learn/)。核心課程不需安裝 npm 套件、金融帳戶、即時行情或券商連線。

26 個 Python 選做活動預估另加 400 分鐘，首次設定約 10–15 分鐘，不取代 30 小時核心。瀏覽器使用固定 Pyodide 314.0.7（Python 3.14.2）；本機學習包使用 Python 3.8 以上及標準函式庫。程式語法、識別字、原始範例程式內註解與部分原生錯誤訊息保留英文；教學說明、提示、數值檢查及學習包 README 為繁體中文。

## 語系與評量調整

- 所有數值、日期、公式、答案、關鍵題與核心學習時間維持原版；£ 仍是英鎊，沒有換成新臺幣或導入臺灣投資／稅務法規假設。
- 中文與英文進度分開儲存，不自動移轉、同步或合併。語言切換保留相對應頁面、查詢參數與片段。
- 中文專題為 **1,200–1,600 個漢字**。只計 U+3400–U+4DBF、U+4E00–U+9FFF、U+F900–U+FAFF；不計數字、拉丁字母、標點、空白。這是中文篇幅要求，不是語言能力或品質評分，也未宣稱與英文篇幅經實證驗證等值。英文版仍是 600–800 個英文單字。
- 核心算術檢查保留；文字理由、研究卡與備忘錄仍由學習者自我檢視。正報酬不是通過條件。
- 圖解提供播放／暫停及逐步控制；減少動態效果偏好下改用手動步驟，另有不需 JavaScript 的完整文字與 CSV。

## 重新產生與檢查

開發檢查需要 Node.js 24 以上，不需 `npm install`。

```sh
npm run build:all
npm test
npm run test:python
```

臺灣語系的編輯來源在 `locales/zh-TW/`，`dist/zh-tw/` 是產生結果，請不要只修改產生結果。英文資產先建立，再產生介紹頁，最後產生中文頁面與雙語切換。詳見 [語系建置說明](docs/localization.md)及[獨立審查紀錄](review/zh-TW/review.md)。
